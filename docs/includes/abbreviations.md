*[MysteryBox]: Nebius's secret manager. Secrets are referenced by id (mbsec-…) or by version id (mbsecver-…).
*[preset]: The machine size on a Nebius platform, such as 1gpu-16vcpu-200gb: GPUs, vCPUs, and memory.
*[presets]: Machine sizes on a Nebius platform, such as 1gpu-16vcpu-200gb: GPUs, vCPUs, and memory.
*[idempotency key]: A value sent with a create, so that a retried request returns the resource the first one made instead of making a second.
*[Object Storage]: Nebius's S3-compatible storage. A bucket mounts into a container as an s3:// volume.
